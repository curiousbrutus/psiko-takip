# **App Name**: PsikoTakip

## Core Features:

- User Registration: User registration with email and password using Firebase Authentication.
- User Login: Secure user login with email and password via Firebase Authentication.
- Welcome Message: Display of a personalized welcome message upon successful login.
- User Logout: Logout functionality to securely end the user session and clear tokens.
- Data Storage: Storage of user data and psychological test results in Firestore.
- AI Test Interpretation: AI powered tool to analyze psychological test results, to generate personalized insights for users, offering guidance based on results and indicating the severity of potential issues, by evaluating their results against predefined thresholds.

## Style Guidelines:

- Primary color: A calming teal (#4DB6AC) to promote a sense of peace and tranquility, aligning with mental health support.
- Background color: Light, desaturated teal (#E0F2F1) to maintain a soothing visual environment without causing distraction.
- Accent color: A gentle, analogous green (#80CBC4) to subtly highlight interactive elements and key information.
- Body and headline font: 'PT Sans' for a balanced, accessible design suitable for both headings and body text.
- Use minimalistic, monochrome icons to represent different sections and functionalities of the app.
- Employ a clean, card-based layout for test results and user information to improve readability and navigation.
- Incorporate subtle, non-intrusive animations for transitions and feedback to enhance the user experience.
